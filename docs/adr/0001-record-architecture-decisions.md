# ADR 0001: Record architecture decisions

Date: 2019-02-11. Status: accepted. Ticket: MBZ-31.

We will keep ADRs in `docs/adr/` in this repository, numbered, in the Nygard format, because the
Confluence space for Meridian Business was archived twice in 2018 and nobody could find the
decisions afterwards. CSWT architecture (@meridian/cswt-architecture) reviews anything in this
directory per CODEOWNERS.

Superseded decisions are not deleted; the status line changes.
